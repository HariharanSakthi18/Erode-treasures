# Erode Trails And Treasures

Build a modern, responsive tourism website called “Erode Explore – Discover the Beauty of Erode” for my MCA college project and developer portfolio.

Technologies: HTML5, CSS3, and vanilla JavaScript. Create three separate files: index.html, style.css, and script.js.

The tourism experience supports English, Tamil, Malayalam, and Hindi. Choose a language from the navbar; the preference is saved in the browser and applies to the standalone page and hosted destination views. Use the navbar’s sun/moon control to switch between warm beige-and-forest-green light mode and deep-green-and-charcoal dark mode; the theme is saved in the browser.

Design: Premium travel website with forest green and cream colours, beautiful destination photos, elegant typography, rounded cards, smooth hover effects, and mobile-friendly layouts.

Include:

Home page with a scenic hero image, introduction, and search bar.

Tourist destination cards with photos, descriptions, categories, and locations.

Search functionality and category filters.

Destination details with Google Maps directions.

Favourites saved using localStorage.

Travel guide, suggested itineraries, About section, and footer.

Tourist places: Kodiveri Dam, Bhavanisagar Dam, Varattupallam Dam, Kunderipallam Dam, Vellode Bird Sanctuary, Sathyamangalam Tiger Reserve, Bannari Amman Temple, Bhavani Sangameshwarar Temple, Chennimalai Murugan Temple, Thindal Murugan Temple, Magudeswarar Temple, Government Museum Erode, Periyar Memorial House, Kodumanal Archaeological Site, Bhavani Jamakkalam Weaving Heritage, VOC Park, Kalingarayan Canal and Anicut, Kongalamman Temple, Aarudra Kabaaleeswarar Temple, and Chillout Theme Park.

Ensure all features work correctly, use accurate information and relevant photographs, and make the website visually attractive and responsive.

Teaching approach: Show the design first, then build step by step. Explain the HTML, CSS, and JavaScript in simple English suitable for a beginner. Provide complete code and instructions for running the project in VS Code.
